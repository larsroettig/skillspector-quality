# Hash-pinned build inputs for the ClusterFuzzLite image.
#
# Installed with `--require-hashes`, so every artifact pip resolves must match one of the
# digests below; an unpinned or substituted package fails the build rather than silently
# entering the fuzzing image (OpenSSF Scorecard: Pinned-Dependencies).
#
# atheris is the fuzzing engine. Pinned to 3.0.0 (not the newer 3.1.0) because the base-builder
# image ships Python 3.11 and atheris only started publishing cp311 wheels again as of 3.0.0;
# 3.1.0 only ships cp312+ wheels, which makes `pip install --require-hashes` fail to resolve.
# hatchling and its dependencies (packaging, pathspec, pluggy, tomlkit, trove-classifiers, and
# tomli on <3.11) are the build backend for `pip install /src`, which runs with
# `--no-build-isolation` so that pip uses these verified copies instead of fetching an unpinned
# hatchling from PyPI at build time. In `--require-hashes` mode every one of hatchling's
# dependencies must be pinned here too, or pip refuses to resolve them.
#
# pyyaml is a *runtime* dependency of the fuzz target, not a build input. `pip install /src`
# runs with `--no-deps`, so nothing else pulls it in, and PyInstaller can only bundle what is
# importable at build time — without it the fuzz target builds cleanly and then dies at
# import with "No module named 'yaml'". It is the only third-party runtime import the target
# reaches; everything else on that path (config, models) is stdlib.
#
# Dependabot keeps these current (see .github/dependabot.yml, pip ecosystem).
